我想製作一個結合 OpenAI LLM 的記帳網頁 APP。
為了方便本地運行、開發與未來部屬，請幫我採用以下技術棧：
- 前端：React + Tailwind CSS (使用 Vite 建立，前端只負責 UI 互動與打 API)
- 後端：Python (FastAPI) (負責本地資料儲存、花費計算與對接 OpenAI)

規格與架構要求如下：

1. 【獨立 LLM 服務模組】：
   後端必須將引入 LLM 的區塊獨立成一個 Python 模組（例如 llm_service.py），以便後續更換其他 LLM（如 Gemini, Claude）時，不需大幅改動其他後端程式與前端程式。

2. 【資料儲存與參數定義】：
   後端負責紀錄與計算，並提供 API 給前端查詢以下數據：
   - 今日總花費
   - 本月總花費
   - 大魔王支出（每個月固定支出的大額花費，如房租、電信費等，由 LLM 判斷）
   - 日常支出（大魔王花費以外的小額花費）
   資料請儲存在本地（可使用簡單的 JSON 檔案或 Python 內建的 SQLite 資料庫）。

3. 【前端輸入介面與資料儲存】：
   - 介面要可以新增每一筆記帳，包含：物品名稱、金額、日期。
   - 包含一個獨立的留言區。
   - 每次點擊送出時，必須包含「一或多筆記帳資料」與「一則留言」。
   - 送出後，後端將資料存入本地，並自動計算與更新「今日總花費」和「本月總花費」。

4. 【後端 Prompt 包裝】：
   當後端收到前端傳來的數筆記帳與留言後，在 Python 後端將這些資料（物品、金額、日期、留言、今日總花費、本月總花費）包裝成 Prompt，並發送給 OpenAI API。

5. 【AI 記帳結構化分類】：
   - 請利用 Python 的 Pydantic 定義 OpenAI 的 Structured Outputs（結構化輸出），強迫 LLM 必須針對每一筆記帳回傳正確的分類結果（"大魔王支出" 或 "日常支出"）。
   - 後端收到 AI 回傳的分類後，更新本地數據，分別累加大魔王支出與日常支出。

6. 【AI 評論功能】：
   請 LLM 根據本次記帳內容與使用者的留言，產生一段繁體中文的 AI 評論與理財建議，並一同回傳給前端顯示。

請幫我產出這個專案的完整檔案結構、FastAPI 後端程式碼（包含 Pydantic 設定、SQLite/JSON 儲存、OpenAI 對接），以及 React 前端的主介面程式碼。
